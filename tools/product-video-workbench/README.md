# Product Video Workbench

Reusable software-promo video workspace. The Agent Treasury V2 film is its first production.

## Pipeline

1. Product truth and scenario script
2. Real browser/mobile captures
3. Neural narration with word timing
4. Remotion motion design and scene composition
5. FFmpeg media validation and contact-sheet review

Run `npm install`, `npm run capture`, then `npm run studio` for preview or `npm run render` for MP4 output. The capture step requires the local Agent Treasury unified service at `http://127.0.0.1:3333`.

The reusable components are host-AI chat, phone shell, center approval, corner notifications, product proof, bilingual safe-area subtitles, and audio-led timing.
