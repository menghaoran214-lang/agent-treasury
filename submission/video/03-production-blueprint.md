# Agent Treasury 三分钟参赛视频制作蓝图

## 制作策略

- 目标：让评委在三分钟内理解 Agent Treasury 的必要性、真实工作流和可扩展边界。
- 核心结论：钱包负责付款；Agent Treasury 是安装在 AI 中的财务、采购和会计 Skill。
- 画幅：1920×1080，16:9，30fps。
- 语言：中文旁白；中文在上、英文在下的双语字幕。
- 视觉：现有深黑、灰白、金色品牌体系；真实 UI 录屏为主体。
- 事实边界：BSC-USDT 是真实支付证明；其他钱包、x402、订阅和跨宿主系统通知标记为扩展方向。

## 声音设计

- BGM：无歌词、克制的科技感电子节奏，约 90–105 BPM；旁白期间压低 15–20dB。
- 开头：轻微低频 impact，突出“该不该付”。
- 页面切换：短促柔和 whoosh，不连续堆叠。
- 自动完成：清脆单次提示音。
- 审批：轻微警示提示，不制造危险感。
- 拦截：短促低频错误音。
- 结尾：音乐轻微抬升后 0.8 秒淡出。

## 录制验收点

1. 录制使用隔离的 mock 数据库，真实钱包不参与演示操作。
2. 自动、审批、异常三种状态必须由真实按钮触发，不用静态图伪装。
3. 账本、收据、导入和中英文切换均拍真实页面。
4. 任何钱包地址、登录信息、二维码和本机路径不得进入画面。
5. 最终配音后按实际语速重新对齐 SRT 时间码。
